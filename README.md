Learn Python — Interactive Lessons

by Habib

A hands-on, 12-lesson interactive course for learning Python, built as a static website. Every lesson has a real, editable code box — code runs live in the browser (via [Pyodide](https://pyodide.org)), no server or install required.

Lessons

1. Say Hello — `print()`
2. Variables
3. Numbers & Math
4. Strings
5. Lists
6. Making decisions — `if` / `elif` / `else`
7. Loops
8. Functions
9. Dictionaries
10. Tuples & Sets
11. Handling errors — `try` / `except`
12. Classes

Each lesson includes a short explanation, an editable code example, a challenge, and a 2-question quiz with instant feedback.

Live site

Enable **GitHub Pages** in this repo's Settings → Pages (source: `main` branch, root folder) to get a live URFiles

- `index.html` — homepage / lesson overview
- `lesson-01.html` … `lesson-12.html` — one page per lesson
- `styles.css` — shared styling
- `app.js` — shared logic (code execution, quizzes, progress tracking)
