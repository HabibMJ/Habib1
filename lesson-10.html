Tuples & Sets

A tuple is like a list but unchangeable once created — written with parentheses, e.g. (x, y). Good for values that shouldn't change, like coordinates.

A set holds unique values with no duplicates and no guaranteed order, written with curly braces — great for removing duplicates or checking membership fast.

If you try to modify a tuple after creating it, Python raises an error — that immutability is the whole point.
