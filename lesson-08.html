Lesson 8 · Reusable code

Functions

A function packages up code you want to reuse. Define it with def, give it a name and parameters, and call it whenever you need it.

return sends a value back out of the function so you can use it elsewhere.

Small, well-named functions are how real programs stay readable as they grow.
Try it yourself

Write a function double(n) that returns n * 2, then print double(21).
