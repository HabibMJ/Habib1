Lesson 12 · Objects

Classes

A class is a blueprint for creating objects that bundle data and behavior together. __init__ sets up a new object's starting values.

self refers to the specific object being used — every method inside a class takes it as the first parameter.

Think of a class as a cookie cutter, and each object you create from it as one cookie — same shape, different details.
